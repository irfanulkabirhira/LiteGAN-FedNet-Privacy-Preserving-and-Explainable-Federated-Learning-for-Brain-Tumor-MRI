# LiteGAN-FedNet-Privacy-Preserving-and-Explainable-Federated-Learning-for-Brain-Tumor-MRI
LiteGAN-FedNet: An explainable federated learning framework for brain tumor MRI classification. Integrates ResNet18 feature extraction, cGAN-based feature augmentation, PCA compression, and XAI methods (Grad-CAM, SHAP, LIME) for privacy-aware distributed medical AI.
